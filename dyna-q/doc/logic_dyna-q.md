# Dyna-Qの学習の仕組み

ここでは、**Dyna-Q（ダイナ・キュー）**の「学習の仕組み」を
図解レベルでわかりやすく説明します。

---

## 🔹 1. Dyna-Q とは何か？

Dyna-Q は、
通常の **Q-learning（モデルフリー学習）** に
**環境モデル（モデルベース学習）** を組み合わせた方法です。

つまり：

> 「実体験で学びながら、同時に頭の中のシミュレーションでも学ぶ」
> という二重の学習構造を持っています。

---

## 🔸 2. 通常の Q-learning の復習

通常の Q-learning はこう動きます👇

1. エージェントが状態 ( s ) にいる
2. 行動 ( a ) を選び、環境から報酬 ( r ) と次状態 ( s' ) を得る
3. Q値を更新：

[
Q(s, a) \leftarrow Q(s, a) + \alpha \bigl[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \bigr]
]

これを「実際の経験」に基づいてひたすら繰り返します。

---

## 🔹 3. Dyna-Q の追加要素（内部モデル）

Dyna-Q では、上記に加えて「**内部モデル**」を作ります。

内部モデルとは：

[
Model(s, a) \rightarrow (s', r)
]

つまり、「状態 (s) で行動 (a) をとると、こうなるはずだ」という予測モデルです。

---

## 🔸 4. Dyna-Q の学習ステップ

1回の「経験」に対して、次のような学習をします。

---

### 🧩 Step 1：実環境で1ステップ学習（Q-learning と同じ）

実際に行動して得たデータを使って Q値を更新：

[
Q(s, a) \leftarrow Q(s, a) + \alpha \bigl[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \bigr]
]

---

### 🧠 Step 2：内部モデルを更新

得られた遷移情報 ((s, a, r, s')) をモデルに記録：

[
Model(s, a) = (s', r)
]

これで、「この状態・行動ではこうなる」と覚えます。

---

### 💭 Step 3：内部モデルを使った“仮想学習（Planning）”

内部モデルから過去の経験をサンプリングして、
仮想的にQ-learningを繰り返します：

[
Q(s, a) \leftarrow Q(s, a) + \alpha \bigl[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \bigr]
]

（式はQ-learningと同じですが、ここでは実環境を使わず「頭の中で更新」します）

この「仮想更新」を1回の実経験につき ( n ) 回くらい行います。

---

## 🔹 5. Dyna-Q 全体の流れ（擬似コード）

```python
for each episode:
    initialize s
    while not done:
        # ---- 実環境とのやり取り ----
        a = policy(Q, s)
        s_next, r = env.step(a)

        # 1. 実際のQ更新
        Q[s, a] += α * (r + γ * max(Q[s_next, :]) - Q[s, a])

        # 2. モデルを更新
        Model[s, a] = (s_next, r)

        # 3. モデルを使って仮想学習を n 回行う
        for i in range(n):
            s_sim, a_sim = sample_from(Model)
            s_next_sim, r_sim = Model[s_sim, a_sim]
            Q[s_sim, a_sim] += α * (r_sim + γ * max(Q[s_next_sim, :]) - Q[s_sim, a_sim])

        s = s_next
```

---

## 🔸 6. 直感的な理解

| 学習段階           | 使う情報    | 意味          |
| -------------- | ------- | ----------- |
| 実学習            | 実際の行動結果 | 経験から学ぶ      |
| 内部モデル更新        | 状態遷移の記録 | 経験を記憶       |
| 仮想学習（Planning） | モデルを再利用 | 思い出し学習・想像学習 |

---

## 🔹 7. メリットまとめ

| 特徴        | 説明                      |
| --------- | ----------------------- |
| サンプル効率が高い | 実体験1回で複数回の学習ができる        |
| 忘れにくい     | 過去の知識をモデルで再利用できる        |
| 適応が早い     | 環境が変わってもモデルを更新すれば再学習が速い |

---

## 🔻 8. 欠点（注意点）

* モデルが不正確だと、誤ったQ更新を引き起こす
* 高次元状態では、モデル構築が難しい（→ Deep Dyna-Q などが発展）
