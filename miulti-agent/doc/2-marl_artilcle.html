昨日作成したコード"情報共有と継続的な協調に焦点を当てた、別の代表的な協調型MARLの例題として、「複数のセンサーによる災害現場の探索（Multi-Sensor Search & Coverage）」"を解くアルゴリズムを使って問題を解こうとしています。

尚、解説ではエージェントである動作物をドローン（エージェント）と仮定しまう。 今回作成したアルゴリズムは、各ドローンが同じニューラルネットワークを使って意思決定を行う、協調型MARL（Multi-Agent Reinforcement Learning）の代表的な手法です。

今回アルゴリズムの概要

今回採用してている主なアルゴリズムは、以下の要素で構成されています。

1. 深層強化学習 (DQN)

項目 説明 目的
DQN Q学習にディープニューラルネットワーク（NN）を組み込んだ手法。NNが各状態での最適な行動のQ値（将来得られる報酬の期待値）を近似します。 複雑な環境状態（マップ全体）を直接入力として受け取り、最適な行動を予測する。
ターゲットネットワーク 予測のターゲット値（QtargetQ_{target}Qtarget​）の計算に使用する、重みが固定されたネットワーク。 学習を安定させる。（DQNの最も重要な安定化技術）
経験再生バッファ 過去のエージェントの経験 (状態、行動、報酬、次の状態) を保存するメモリ。 経験をランダムにサンプリングして学習に使うことで、データの相関を減らし、学習を安定させる。

2. 構造的特徴 (Dueling DQN と CNN)

項目 説明 目的
CNN 畳み込みニューラルネットワークをQネットワークに使用。 マップ情報（探索済み/未探索エリア）という空間的なデータから、未探索エリアの場所や、移動しやすい経路といった特徴量を効率的に抽出する。
観測 (State) 入力は 2 チャンネルの画像形式です。Ch0: 共有探索マップ、Ch1: 自分の位置（ワンホットエンコーディング）。 NNに「今、どこにいるか」と「チーム全体でどこまで探索したか」を同時に伝える。

3. マルチエージェントの協調 (共有エージェント脳)

項目 説明 協調学習のポイント
共有エージェント (SharedAgent\text{SharedAgent}SharedAgent) すべてのドローンが、単一の同じニューラルネットワーク（policy_net\text{policy\_net}policy_net）の重みを共有して意思決定を行う。 完全に協調的なタスク（探索率の最大化）において、学習された知識（例: 「未探索エリアには優先して向かう」）をチーム全体で瞬時に共有できる。
報酬 チーム全体で新しく発見したマスの数に基づいてチーム全員に同じ報酬を与える。 ドローンが個々の利己的な行動ではなく、「チーム全体の目標達成」に貢献する行動（分散して探索する）を学習するように誘導する。

🏃 学習プロセス (学習ループ) の流れ

  1. 初期化: 環境と共有ネットワーク（policy_net\text{policy\_net}policy_netとtarget_net\text{target\_net}target_net）を初期化し、すべてのドローンをマップ上にランダムに配置します。
  2. 行動決定 (ϵ\epsilonϵ-greedy):
    • 一定確率 (ϵ\epsilonϵ) でランダムな行動を取り（探索）、それ以外では policy_net\text{policy\_net}policy_net の出力するQ値が最大の行動を選択します（活用）。
  3. 環境実行と経験保存:
    • すべてのドローンが同時に行動を実行し、環境が次の状態へ遷移します。
    • 各ドローンは、その経験 (state\text{state}state, action\text{action}action, next_state\text{next\_state}next_state, reward\text{reward}reward, done\text{done}done) を共通の ReplayMemory\text{ReplayMemory}ReplayMemory に保存します。
  4. モデルの最適化:
    • ReplayMemory\text{ReplayMemory}ReplayMemory から経験をランダムにサンプリングし、DQNの損失関数（予測Q値とターゲットQ値の差）を計算します。
    • 共有ネットワークの重みを更新し、全てのドローンがその学習結果を即座に利用できるようにします。
  5. ターゲットネットワークの更新:
    • 一定のエピソードごと（TARGET_UPDATE\text{TARGET\_UPDATE}TARGET_UPDATE）に、policy_net\text{policy\_net}policy_net の重みを target_net\text{target\_net}target_net にコピーし、ターゲット値を安定させます。

このプロセスにより、ドローンたちは重複を避け、効率的にマップを分割して探索する最適な協調戦略を、ネットワークの重みとして学習します。
