# マルチエージェントの例題

マルチエージェント強化学習（ **MARL** ）の概念を理解するための簡単な例題をいくつかご紹介します。

MARLは、複数のエージェントが同じ環境内で相互作用しながら学習する分野です。相互作用の性質によって、問題は大きく「 **協調的** 」、「 **競争的** 」、または「 **混合的** 」に分類されます。

---

## 🤝 協調的な例題 (Cooperative Tasks)

すべてのエージェントが**共通の目標**を持ち、協力して最大の総合報酬を得ることを目指します。

### 1. 搬送ロボットの協調 (Cooperative Transport)

* **設定** : 2台のロボットが、1台だけでは運べない**重い荷物**を特定のゴール地点まで運ぶタスク。
* **エージェント** : 2台の搬送ロボット。
* **目標** : 荷物を落とさずに最短時間でゴールに到達すること。
* **相互作用** : ロボットは互いの位置と力を調整し、協調して荷物にかかる力をバランスさせる必要があります。一方のロボットが速すぎたり、逆方向へ力を加えたりすると、全体の報酬（タスク完了までの時間や荷物の安定性）が悪化します。

### 2. 交通信号機制御 (Traffic Signal Control)

* **設定** : 相互に接続された複数の交差点に設置された信号機を制御するタスク。
* **エージェント** : 各交差点の信号機。
* **目標** :  **全体の車両の待ち時間** （渋滞）を最小限に抑えること。
* **相互作用** : ある交差点の信号機が青の時間を長くすると、その先の交差点に車両が流れ込み、そこの渋滞を悪化させる可能性があります。全体最適を目指すため、各信号機は連携して最適なタイミングを学習する必要があります。

## ⚔️ 競争的な例題 (Competitive Tasks)

エージェントが互いに**対立**し、一方の報酬が最大化されると、もう一方の報酬が最小化される**ゼロサムゲーム**になることが多いです。

### 3. ポンゲーム（Pong）/ エアホッケー

* **設定** : 2つのパドル（エージェント）がボールを打ち合い、相手のゴールに入れることを競うゲーム。
* **エージェント** : プレイヤー1 (パドルA) と プレイヤー2 (パドルB)。
* **目標** : 自分のゴールを守り、相手のゴールにボールを入れる（相手の報酬を下げる）。
* **相互作用** : プレイヤー1がボールを打つ戦略を学習すると、プレイヤー2はそれを防御・反撃する戦略を学習する必要があります。互いの戦略が**進化**し続ける（ **Emergent Behavior** ）のが特徴です。

### 4. 鬼ごっこ (Tag) または 捕食者と獲物 (Predator-Prey)

* **設定** : 1匹以上の **捕食者** （Predators/オニ）が、環境を動き回る **獲物** （Prey/逃げる側）を捕まえることを目指します。
* **エージェント** : 捕食者と獲物。
* **目標** : 捕食者は獲物を捕まえる（報酬+）。獲物は捕食者から逃げ続ける（報酬+）。
* **相互作用** : 競争と協調（捕食者同士が獲物を包囲するなど）が入り混じる場合がありますが、基本構造は競争的です。

---

## 🎨 混合的な例題 (Mixed Tasks)

一部のエージェントが協力し、同時に他のエージェントとは競争する、またはエージェント同士の目標が完全に一致しないタスクです。

### 5. サッカーなどのチームスポーツ

* **設定** : 2つのチームが対戦するゲーム。
* **エージェント** : 各チームの個々の選手。
* **目標** :
* **チーム内** : チームメイトと**協調**してパスを繋ぎ、守備を行う。
* **チーム間** : 相手チームと**競争**してゴールを決める。
* **相互作用** : エージェントは、**ローカル**な協調と**グローバル**な競争という2種類の相互作用を同時に考慮して行動を決定する必要があります。
