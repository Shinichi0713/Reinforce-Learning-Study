はい、PyTorchで実装に取り組むための、非常にシンプルな**競争的マルチエージェント強化学習（MARL）**の例題を作成します。

この例題は「 **シングル・ステップ・ゼロサム・ゲーム** 」の形式をとり、各エージェントが一度の行動で報酬を得て終了します。これは、複雑なゲームよりも簡単に**Q-Learning**などの基本アルゴリズムをMARL環境に適用する方法を理解するのに役立ちます。

## 🎯 例題：じゃんけんゲーム (Rock-Paper-Scissors)

**エージェントの競争と学習**を最もシンプルに表現できるのが、このゼロサムのじゃんけんゲームです。

---

## 1. 環境 (Environment) の設計

### A. 環境設定

* **状態 (**$S$**)** : 唯一の状態 **$S_0$** のみとします。エージェントは相手の過去の行動を記憶せず、毎回同じ状態からスタートします。
* **行動 (**$A$**)** : 各エージェントの行動空間は **$\{0, 1, 2\}$** です。
* **$A=0$**: グー (Rock)
* **$A=1$**: チョキ (Paper)
* **$A=2$**: パー (Scissors)
* **エージェント** : 2体 (Agent 1, Agent 2)。

### B. 報酬関数 (**$R$**)

これは**ゼロサムゲーム**です。つまり、一方の利得はもう一方の損失と等しくなります。

| **Agent 1 の行動** | **Agent 2 の行動** | **R1 (Agent 1 の報酬)** | **R2 (Agent 2 の報酬)** |
| ------------------------ | ------------------------ | ----------------------------- | ----------------------------- |
| 勝つ                     | 負ける                   | **$+1$**              | **$-1$**              |
| 負ける                   | 勝つ                     | **$-1$**              | **$+1$**              |
| 引き分け                 | 引き分け                 | **$0$**               | **$0$**               |

---

## 2. PyTorchで実装する要素

### A. エージェントのモデル（Q-Network）

各エージェントは、自分の最適な行動を見つけるために、行動価値関数 **$Q(s, a)$** を近似する**ニューラルネットワーク**を持ちます。

**モデル構造の例:**

**Python**

```
import torch
import torch.nn as nn
import torch.optim as optim

class QNetwork(nn.Module):
    def __init__(self, input_size, output_size):
        super(QNetwork, self).__init__()
        # この例では状態が1つ(S0)なので、入力サイズは1または単なるバイアスとして機能
        self.fc = nn.Linear(input_size, 32) # 全結合層
        self.output = nn.Linear(32, output_size) # 出力は行動数(3)

    def forward(self, x):
        x = torch.relu(self.fc(x))
        return self.output(x)

# エージェント1, 2のネットワークを定義
input_size = 1 # S0の状態を表すダミー入力
action_size = 3
agent1_net = QNetwork(input_size, action_size)
agent2_net = QNetwork(input_size, action_size)
```

### B. 学習アルゴリズム（DQNの簡略版）

各エージェントは**独立して**学習しますが、もう一方のエージェントの行動を**環境の一部**として扱います。これは **Independent Q-Learning (IQL)** と呼ばれる、最もシンプルなMARLのアプローチです。

**学習ステップ:**

1. **行動選択** : エージェント1は、**$\epsilon$**-greedy戦略に基づき、現在のQ値から行動 **$a_1$** を選択します。エージェント2も同様に行動 **$a_2$** を選択します。
2. **実行と報酬** : 選択された行動の組み合わせ **$(a_1, a_2)$** に基づいて、環境から報酬 **$R_1$** と **$R_2$** を受け取ります。
3. Q値の更新: エージェント1は、受け取った $R_1$ を使って自身のQ値を更新します。
   $$
   Q(S_0, a_1) \leftarrow Q(S_0, a_1) + \alpha [R_1 - Q(S_0, a_1)]
   $$

   エージェント2も同様に $R_2$ を使って更新します。

### C. 最適な方策

このじゃんけんゲームの最適な方策（Nash均衡）は、**完全にランダムな行動** (各行動を **$1/3$** の確率で選択) です。もしエージェントが特定のパターンを学習し始めた場合、もう一方のエージェントはそのパターンを利用して勝つことを学習し、**学習が振動し続ける**というMARL特有の現象が見られます。

このシンプルな例を通して、競争的環境での学習の不安定さや、相手の行動が自分のQ値更新に与える影響（ **非定常な環境** ）を体験できます。
