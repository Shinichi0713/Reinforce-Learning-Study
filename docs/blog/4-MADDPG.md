分散型のMARL最終の説明です。

 

今回は、MADDPG（Multi-Agent Deep Deterministic Policy Gradient） についてです。背景から特徴、解決できる問題例まで説明します。

---

# 🧠 **MADDPGとは？（概要）**

**MADDPG** は、OpenAI（Lowe et al., 2017）によって提案された
**マルチエージェント強化学習（MARL）** 向けの手法で、

### 👉 **マルチエージェント版 DDPG（連続値アクション対応 Actor–Critic）**

です。

特に、

* **競合（敵対）環境**
* **混合（協調+競争）環境**
* **連続値アクションが必要な制御系**

に強いのが特徴です。

---

# 🎯 **MADDPG が解決したかった課題**

従来の強化学習では、複数エージェントが同時に学習すると

---

## 🔸 **課題1：非定常性（Non-stationarity）**

他のエージェントも学習して戦略を変えるため、
**環境のダイナミクスが常に変化してしまう**。

→ 従来の Q 学習や DDPG では改善困難。

---

## 🔸 **課題2：部分観測**

各エージェントは環境全体を観測できない
（Dec-POMDP問題）。

---

## 🔸 **課題3：競合環境での学習困難**

協調タスクだけでなく、

* 対戦ゲーム
* 防衛 vs 攻撃
  など、敵がいる環境では reward が混乱しやすい。

---

➡ **MADDPG は CTDE（集中学習・分散実行）によって解決する。**

---

# 🔬 **仕組み（どう動く？）**

MADDPG は **Actor-Critic 方式**ですが、

| Actor                   | Critic                              |
| ----------------------- | ----------------------------------- |
| エージェントごとに独立             | 中央集中式                               |
| 各エージェントは自身の観測 o_i のみで行動 | Critic は全エージェントの情報 (s, a₁,…,aₙ) を利用 |

---

### 🧠 学習方法のポイント

各エージェント i の Critic は

```
Q_i(s, a_1, …, a_N)
```

を出力でき、

更新式は

```
L_i(θ_i) = E[(Q_i(s, a_1,…,a_N) − target)^2]
```

Actor は

```
∇J(φ_i) = E[∇_a Q_i(s,a_1,…,a_N) ∇_{φ_i} π_i(o_i)]
```

のような DDPG と同様の deterministic policy gradient。

---

## 📌 CTDE の利点

### 🔹 学習時は全情報を使う → 学習が安定

### 🔹 実行時は観測だけで行動できる → 実用

---

# ⭐ **MADDPG の特徴**

| 特徴                     | 内容                |
| ---------------------- | ----------------- |
| 連続値アクション対応             | DDPG ベースで制御タスクに強い |
| Actor は分散 / Critic は集中 | CTDE              |
| 非定常性の軽減                | 全体情報を見た critic    |
| 競争 + 協調どちらも対応          | ゲームにも制御にも使える      |
| Replay buffer 共有       | 経験効率向上            |

---

# 🏆 **MADDPG が解ける問題例**

| 分野         | 具体例                        |
| ---------- | -------------------------- |
| マルチロボット    | 協調搬送、編隊飛行、ドローンの障害物回避       |
| 自動運転       | 交差点での協調判断、合流制御             |
| 交通制御       | 車両流量の最適制御                  |
| 競技シミュレーション | Predator–Prey ゲーム、サッカー、格闘戦 |
| ロボティクス     | マニピュレータ協調作業                |
| 軍事シミュレーション | チーム vs チームの戦略学習            |

---

### 🎮 例：Predator–Prey（捕食者 vs 被捕食者）

| 捕食者チーム   | 被捕食者       |
| -------- | ---------- |
| 協力して囲み込み | 逃げ切り戦略を最適化 |

→ **協調＋競争** の典型例
MADDPG の代表的ベンチマーク。

---

### 🚁 例：複数 UAV の隊列制御

* 隊列を維持しながら移動
* 障害物回避
* 飛行安定化（連続アクション）

---
