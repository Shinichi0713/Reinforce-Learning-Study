# ✅ **1. 概要：価値分解学習（Value Decomposition, VDN）とは？**

**価値分解学習（Value Decomposition）** は、
「複数のエージェントが協調してタスクを行う MARL のために、
**グローバルな価値関数をエージェント個々の価値関数に分解する手法**」です。

代表例：

| 手法                                                          | 概要                                      |
| ----------------------------------------------------------- | --------------------------------------- |
| **VDN (Value Decomposition Networks, Suneel et al., 2017)** | グローバル Q を単純に**足し算**で分解                  |
| **QMIX (Rashid et al., 2018)**                              | グローバル Q を、各エージェント Q の**単調性制約つき混合**として分解 |
| **QTRAN (Son et al., 2019)**                                | 単調性制約を緩和し、より一般的な分解を実現                   |

これらは総称して **価値分解系（Value Factorization / Value Decomposition）** と呼ばれることもあります。



# ❓ **2. 価値分解学習が解決したかった課題（VDN/QMIX/QTRAN 系の問題設定）**

協調型 MARL では、以下の問題が重大です：



## 🔸 **問題1：環境が部分観測（Dec-POMDP）**

* 各エージェントは環境の一部しか見えていない
* 個別に Q 学習すると協調がうまくいかない



## 🔸 **問題2：「チームとしての報酬」はあっても、個別報酬が無い**

例：StarCraft のユニット

* 報酬 = チーム全体が敵を倒すかどうか
* 各エージェントがどれだけ貢献したか分からない
  → クレジットアサインメント（責任分配）が困難



## 🔸 **問題3：探索が難しい & 大規模になる**

* エージェントが増えると joint action の組合せが指数的に増える
* Q(s, a1, a2, ..., an) を直接学習するのは不可能



➡ **価値分解学習はこれらを解決するための枠組み**です。



# ✨ **3. 価値分解学習(VAE)の特徴**

以下は代表である **VDN / QMIX / QTRAN** に共通する特徴です。



## ① **中央学習・分散実行（CTDE：Centralized Training, Decentralized Execution）**

学習中だけ

* 全エージェントの観測
* 全エージェントの行動
* グローバル報酬

を使えるが、

**実行時は各エージェントが自分の観測だけで行動する。**



## ② **グローバルの Q を、個別の Q に分解**

### ● VDN（最もシンプル）

```
Q_total = Σ_i Q_i
```

### ● QMIX（単調性制約つきの混合）

```
Q_total = MixingNetwork(Q_1, ..., Q_n)
ただし ∂Q_total / ∂Q_i >= 0
```

### ● QTRAN（より一般的な分解）

単調性に縛られない柔軟性を持つ。



## ③ **協調を個別 Q によって実現できる（credit assignment が生じる）**

複数エージェントが協力して最適動作を選択できる。



## ④ **大規模化に強い**

エージェント数が増えても joint action を直接扱わずに学習できる。



# 🗂 **4. この手法で解ける問題例（応用領域）**

価値分解系（VDN / QMIX）は以下の "協調型" タスクで非常に有効です。



## 🛰 ① **マルチロボット協調（ドローン・ロボット群）**

例：

* 複数ドローンで探索
* 複数ロボットで同時搬送
* マルチロボットの連係作業

エージェント間の協調が必要で、交差干渉も起こる。



## 🎮 ② **ゲーム：StarCraft Multi-Agent Challenge（SMAC）**

QMIX 系の代表的ベンチマーク

* 各ユニット（エージェント）が部分観測
* 協調して戦う必要がある
* 個別報酬がない → 価値分解が必要



## 🚗 ③ **自動運転群システム（車車間協調）**

例：

* 合流時の速度調整
* 渋滞回避
* 車列（platooning）制御



## 🚚 ④ **物流・倉庫ロボット**

例：

* Amazon などの倉庫ロボット群の経路協調
* 物資を持ちながら衝突回避して最適動作



## 🏭 ⑤ **工場ラインの協調制御**

* 生産ラインで複数ロボットが工程を分担
* 協調して処理する必要がある
