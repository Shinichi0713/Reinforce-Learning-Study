
続々のMARLの手法です。
今回は、**COMA（Counterfactual Multi-Agent Policy Gradients）** について、
研究背景から仕組み、特徴、解ける問題までを整理して説明します。

---

# 🧠 **1. COMA とは？（概要）**

**COMA（Foerster et al., 2018）** は、
**協調型 MARL（マルチエージェント強化学習）** のために作られた
**アクタ−クリティック方式（Actor–Critic）** の代表的手法です。

特に、

* **credit assignment（誰がどれだけ貢献したか）問題**
* **部分観測 Dec-POMDP**
* **協調報酬しか与えられないタスク**

に強いのが特徴です。

COMA の最大の目玉は：

## 👉 **「反事実ベース Advantage（Counterfactual Advantage）」**

「もし他のエージェントの行動がそのままで、自分だけ別の行動をしたらどうなるか？」
という **反事実的な寄与度（contribution）** を計算し、
各エージェントの学習を安定化させる仕組みです。

---

# 🎯 **2. COMA が解決したかった課題**

MARL の協調問題には、昔から次の2つの大きな難点がありました。

---

## 🔸 **課題1：Credit Assignment（責任分配の難しさ）**

協調型タスクでは、報酬は「チーム全体」の成績で与えられます。

例：

* 敵を倒す → +1
* 倒される → -1
* 個々の行動がどれほど影響したか不明

**→ 個々のエージェントがどう貢献したかが分からず、学習が不安定**

---

## 🔸 **課題2：部分観測（Dec-POMDP）**

各エージェントは環境の一部だけしか観測できない。
→ 協調がさらに困難。

---

## 🔸 **課題3：方策勾配法の高い分散（variance）**

同じ報酬が全員に配られると、
「誰が良い行動をしたか分からない」ため勾配推定のばらつきが大きい。

---

➡ **これらを同時に解決するために考案されたのが COMA**

---

# 🔬 **3. COMA の仕組み（何をしている？）**

COMA は **Actor–Critic** 方式で、

* Actor（各エージェント）：分散実行
* Critic（中央）：集中学習

を採用します。

---

## 💡 仕組みの中心：Counterfactual Advantage

COMA は、各エージェント i の advantage を

```
A_i(a_i, a_-i) 
= Q_total(a_i, a_-i) − Σ_{a'_i} π_i(a'_i | o_i) * Q_total(a'_i, a_-i)
```

のように

### ▼ **自分の行動 a_i を除いて期待値を引く**

ここが反事実的（counterfactual）です。

* 他のエージェント a_-i の行動はそのまま
* 自分の行動だけを別の選択肢に変えて比較

➡ **自分の行動がグローバル報酬にどれだけ寄与したかを正確に測る**

---

### 📌 なぜ良い？

* 各エージェントに**責任を適切に割り当てられる**
* 方策勾配の分散が大幅に減る
* 協調動作が学習しやすくなる

---

# ⭐ **4. COMA の特徴（他手法との違い）**

| 項目                | COMA の特徴                    |
| ----------------- | --------------------------- |
| モデル形式             | Actor–Critic                |
| Critic            | 中央集中型 Q(a₁,…,aₙ,s)          |
| Actor             | エージェントごと（分散実行）              |
| Credit assignment | Counterfactual baseline で実現 |
| 部分観測              | 個々の actor は RNN を使う事が多い     |
| 協調タスク             | 非常に強い                       |

---

## 🔹 特徴①：単純な「足し算分解」（VDN）ではない

VDN のように
`Q_total = Σ Q_i`
などの制約はなく、

### 👉 COMA の Critic は joint-action Q を直接出力できる

→ より柔軟な協調を学習できる

---

## 🔹 特徴②：方策勾配法の高分散を Counterfactual Advantage で解消

baseline を「自分以外を固定した反事実 scenario」で計算するので、
「本当に自分の行動が良かったか？」が正確に分かる。

---

## 🔹 特徴③：CTDE（中央学習・分散実行）

実行時に各エージェントは自分の観測だけで行動できる。

---

# 🏆 **5. COMA が得意な問題例（この手法で解ける問題）**

COMA は **協調型 & 部分観測** のタスクに最適です。

---

## ① **StarCraft Multi-Agent Challenge（SMAC）**

COMA は SMAC で最初に成功した手法の一つ。

例：

* Zealot や Marine の複数ユニットを協調させて敵と戦う
* 報酬はチームの勝敗だけ
* 観測は部分的
  → credit assignment が極めて難しい

COMA は **“誰が敵を倒すのに貢献したか”** を反事実で評価できる。

---

## ② **自律ロボット群（群集ロボット / Swarm robots）**

* 探索タスク
* 分散搬送
* 協調で物体を押すなど

報酬は全体で一つ → COMA 向き。

---

## ③ **マルチ UAV/ドローン協調**

* 地図探索
* 分散監視
* パトロール

他エージェントとの協調が必要。

---

## ④ **交通制御（multi-agent traffic control）**

* 車両群の協調ルーティング
* 信号制御
* 合流時の調整

**credit assignment** が重要な場面で強い。

---

## ⑤ **倉庫ロボットの協調（Warehouse MARL）**

* 複数ロボットが荷物を運ぶ
* 衝突回避と作業分担が必要
  → 反事実 advantage が役立つ

---

# 🎯 **6. まとめ**

| 項目        | 内容                                                |
| --------- | ------------------------------------------------- |
| **手法名**   | COMA（Counterfactual Multi-Agent Policy Gradients） |
| **目的**    | 協調型 MARL の credit assignment と方策勾配の高分散を解消         |
| **最大の特徴** | Counterfactual Advantage（反事実 Advantage）           |
| **方式**    | Actor–Critic（中央集中クリティック + 分散 Actor）               |
| **適用領域**  | StarCraft、ドローン、倉庫ロボット、交通制御など協調必須タスク               |
