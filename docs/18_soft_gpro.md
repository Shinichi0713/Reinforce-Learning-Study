
先日説明した[GRPO](https://yoshishinnze.hatenablog.com/entry/2026/10/12/043000)は2025年に発表されたLLMの強化学習法です。
今年に入って、GRPOの後継手法が開発されているようでしたので、調べてみました。

今回はそんなGRPOの後継手法のうち一つである [SofT-GRPO](https://arxiv.org/pdf/2511.06411) について読んでいきます。

### 概要

SofT-GRPO は、**ソフト思考（soft-thinking）**という推論パラダイムに対して強化学習（RLVR）を適用するためのポリシー最適化アルゴリズムです。

従来の離散トークン Chain-of-Thought（CoT）に対して GRPO は有効ですが、ソフト思考（トークン埋め込みの重み付き和による連続的表現）に対して RLVR を適用するのは困難でした。理由は以下の2点です。

1. **確率性の欠如**: ソフト思考は決定論的であり、探索に必要なランダム性がない
2. **勾配の計算困難**: ソフトトークンへの報酬の帰属（credit assignment）が難しい

SofT-GRPO はこれを解決するため、以下を導入しています。

- **Gumbel ノイズの注入**: トークン確率に Gumbel ノイズを加え、多様なソフト思考パスを探索
- **Gumbel-Softmax**: 事前学習済みの離散トークン埋め込み空間の外に出ないよう、有効なソフトトークンを生成
- **Gumbel 再パラメータ化トリック**: LLM の出力確率分布に対して報酬の帰属を正確に行う勾配推定

### 実験結果

1.5B から 7B パラメータの LLM を用い、5つの数値推論ベンチマークで評価した結果：

- **Pass@1**: 離散トークン GRPO をわずかに上回る（平均 +0.13%）
- **Pass@32**: 大幅な改善（平均 +2.19%）。サンプル数を増やすほどソフト思考の優位性が顕著になる
- **ドメイン外汎化**: ドメイン外ベンチマークでも性能向上を確認

### 主な貢献

1. ソフト思考推論向けの強力な RLVR アルゴリズムを初めて提案
2. Gumbel-Softmax をグループロールアウトに統合し、多様で有効なソフト思考パスを能動的に獲得
3. Gumbel 再パラメータ化による勾配推定を提案し、LLM の出力確率分布への正確な credit assignment を実現
4. 高サンプルレート（Pass@16, Pass@32）で離散トークン GRPO を明確に上回る性能を示した

## 解決しようとした課題

SofT-GRPO が解決しようとした課題は、**「ソフト思考（soft-thinking）推論に対して、強化学習（RLVR）を効果的に適用すること」**です。

具体的には、以下の3つの課題を解決しています。

### 1. ソフト思考への RLVR 適用の困難さ

従来の離散トークン Chain-of-Thought（CoT）に対しては GRPO などの RLVR 手法が有効でしたが、ソフト思考（トークン埋め込みの重み付き和による連続的表現）に対しては RLVR を適用することが困難でした。結果として、ソフト思考 + GRPO の組み合わせは、離散トークン GRPO より性能が劣る状況が続いていました。

### 2. ソフト思考の決定論性（ランダム性の欠如）

ソフト思考はサンプリングに基づく離散トークン CoT とは異なり、決定論的なソフトトークンを生成します。これにより、RLVR に必要な以下の要素が欠けていました。

- **探索の多様性がない**: 多様な推論パスを探索するための確率性（stochasticity）が不足
- **勾配が得にくい**: 方策更新に必要な勾配が計算しにくい

### 3. 報酬の帰属（Credit Assignment）の困難さ

既存の試み（ソフトトークンにガウスノイズを注入する方法など）は、離散トークン RLVR に性能で及びませんでした。主な理由は、**RLVR で得られた報酬の改善分を LLM の logits（出力確率）に正確に帰属させることができなかった**ためです。

## 工夫点

SofT-GRPO の仕組みは、**「ソフト思考（soft-thinking）」という連続的な推論表現に対して、GRPO と同様のグループベース RLVR を適用するための技術群**です。
以下、背景から具体的な3つの柱まで順を追って説明します。

### 1. 前提：ソフト思考（Soft-Thinking）とは

従来の Chain-of-Thought（CoT）は離散トークン列（例：「だから」「計算すると」）を生成します。対してソフト思考は、各ステップで**トークン埋め込みの重み付き和**を生成します。

- 語彙全体の確率分布を出力し、その確率を重みとして各トークンの埋め込みベクトルを足し合わせる
- 結果として「離散トークン1つ」ではなく「連続的なベクトル」が次のステップへ渡される
- 微分可能であり、離散トークンでは表現しにくい抽象的な概念を扱える可能性がある

ただし、これは決定論的（ランダム性がない）ため、そのままでは RLVR に向きませんでした。

### 2. GRPO の基本（復習）

GRPO は以下の流れです。

1. 1つの質問に対して、**グループ（複数の回答パス）**をサンプリング
2. 各回答の報酬を計算し、グループ内の**相対的な優劣**からアドバンテージを算出
3. 良い回答の生成確率を上げ、悪い回答の確率を下げるよう方策を更新

ソフト思考にそのまま適用しようとすると、サンプリングのランダム性がなく、勾配の計算もうまくいきません。

### 3. SofT-GRPO の3つの柱

SofT-GRPO は以下の3つの技術を組み合わせて、上記の問題を解決します。

__① Gumbel ノイズの注入：探索の多様性を確保__

ソフト思考は決定論的なので、同じ質問に対して常に同じ推論パスを辿り、探索が起きません。

- **Gumbel ノイズ**（一種のランダムノイズ）を logits（出力直前のスコア）に加算
- これにより、同じ質問でも**異なるソフト思考パス**が確率的に生成される
- GRPO に必要な「グループ内の多様なサンプル」を確保できる

__② Gumbel-Softmax：有効なソフトトークンを生成__

単純にノイズを加えるだけでは、事前学習済みのトークン埋め込み空間から外れた「意味のないベクトル」が生成される恐れがあります。

- **Gumbel-Softmax** を用いることで、語彙上の確率分布から**滑らかにサンプリング**しつつ、埋め込み空間内に留まるソフトトークンを生成
- 離散トークンの埋め込み空間を「崩さず」に連続的な推論を行える

__③ Gumbel 再パラメータ化トリック：正確な勾配推定__

RLVR で得た報酬を、LLM のパラメータ更新に反映させるには「どの出力確率の変更が報酬向上に寄与したか」を知る必要があります（credit assignment）。

- Gumbel 分布の性質を利用した**再パラメータ化トリック**により、サンプリングのランダム性を「パラメータから独立したノイズ」として分離
- これにより、**報酬の改善分を LLM の出力確率分布（logits）に正確に帰属**させる勾配が計算できる
- 以前の手法（ガウスノイズを直接ソフトトークンに加える方法）ではできなかった、確率分布レベルでの精密な勾配推定を実現

### 4. 全体の流れ

SofT-GRPO の学習は以下のように進みます。

1. **グループロールアウト**: 1つの質問に対し、Gumbel ノイズ注入 + Gumbel-Softmax で複数のソフト思考パスを生成
2. **報酬計算**: 各パスに対して verifiable reward（例：数学問題の正解なら +1）を与える
3. **アドバンテージ算出**: グループ内の相対スコアから各パスの優劣を正規化
4. **方策更新**: Gumbel 再パラメータ化トリックを使い、ソフト思考の生成確率を更新。良いパスの確率を上げ、悪いパスの確率を下げる

## 実験

SofT-GRPO の効果は、論文に記載されている実験設定と結果から、以下のように読み解けます。

### 1. 実験の問題設定

論文では、以下の条件で評価が行われています。

| 項目 | 内容 |
|------|------|
| **モデル規模** | 1.5B、3B、7B パラメータの LLM（複数モデルで一貫した傾向を確認） |
| **タスク** | 数値推論ベンチマーク（数学的・論理的推論が必要な問題） |
| **評価指標** | Pass@1（1回サンプリング時の正解率）と Pass@32（32回サンプリングのベスト正解率） |
| **比較対象** | 離散トークン CoT + GRPO（従来の標準的な手法） |

この設定には意味があります。ソフト思考は「離散トークンでは表現しにくい抽象的概念」を扱えるはずなので、**推論の複雑さが高い数値推論タスク**で評価することで、その優位性を検証しています。

### 2. 実験結果から読み解く効果

__効果①：Pass@1 で離散トークン GRPO をわずかに上回る（平均 +0.13%）__

- 1回だけ回答を生成する場合、ソフト思考 + SofT-GRPO は離散トークン GRPO と同等かわずかに上回る性能
- これは「ソフト思考は微調整なしでも強いが、RLVR を適用するとさらに強くなる」という流れを完結させた結果
- 以前はソフト思考に RLVR を適用しても離散トークン GRPO に勝てなかったが、**SofT-GRPO によって初めてその逆転が実現**した

__効果②：Pass@32 で大幅な改善（平均 +2.19%）__

ここが最も重要な効果です。

- 32回サンプリングしてベストを選ぶ場合、ソフト思考 + SofT-GRPO は離散トークン GRPO を**明確に上回る**
- サンプル数を増やすほど差が広がるということは、**ソフト思考の探索空間が離散トークンより豊か**であることを示唆
- 離散トークンでは「語彙にない表現」が作れないが、ソフト思考では埋め込み空間内の連続的な組み合わせが可能なため、**多様で創造的な推論パス**を生成できる

__効果③：ドメイン外汎化性能の向上__

- 学習時と異なるドメインのベンチマークでも SofT-GRPO は有効
- これは SofT-GRPO が単なる「過学習」ではなく、**推論能力そのものを強化**していることを示唆
- ソフト思考の連続的表現が、離散トークンよりも**抽象的な推論パターンの転移**に適している可能性

### 3. 効果の本質的な読み解き

実験結果から、SofT-GRPO の効果は以下の3層に分解できます。

| 層 | 内容 |
|----|------|
| **技術的効果** | Gumbel-Softmax と再パラメータ化により、ソフト思考に対して初めて「有効な RLVR」が適用可能になった |
| **性能効果** | Pass@1 で同等、Pass@32 で明確な優位。サンプリング数を増やすほどソフト思考の恩恵が大きい |
| **概念的効果** | 離散トークンの語彙制約から解放され、連続的な思考表現による推論の可能性を開いた |

### 4. なぜ Pass@32 で差が大きいのか

これは論文の核心的な示唆です。

- **離散トークン CoT** は語彙に含まれるトークンの組み合わせしか生成できない
- **ソフト思考** は語彙全体の埋め込みを連続的に組み合わせられるため、「語彙にない概念」も中間表現として扱える
- サンプリング数を増やすと（Pass@32）、この表現力の差が**探索の多様性**として現れる
- SofT-GRPO はその多様性を「報酬に基づいて最適化」できるため、単なるランダムサンプリングではなく**報酬を最大化する方向に多様な推論パスを育成**できる

### 5. まとめ：SofT-GRPO の効果

SofT-GRPO の効果は「ソフト思考を強化学習で最適化できた」という技術的達成以上のものです。

1. **離散トークンの語彙制約を超えた推論表現**を RLVR で最適化できるようになった
2. **多数サンプリング時（Pass@32）に顕著な優位性**を示し、ソフト思考の探索空間の豊かさを実証
3. **ドメイン外でも汎化**するため、単なるタスク特化型の過学習ではなく、推論能力の本質的向上と考えられる

つまり、SofT-GRPO は「GRPO をソフト思考に拡張した」だけでなく、**「LLM の推論を離散トークンから連続的表現へと進化させるための基盤技術」** として位置づけられる成果です。

## 総括

SofT-GRPO の本質は、**「離散トークンの語彙制約から解放された連続的な思考表現（ソフト思考）を、初めて強化学習で本格的に最適化できた」** という点にあります。

### なぜこれが重要か

従来の LLM 推論（Chain-of-Thought）は「単語を1つずつ選ぶ」離散トークン方式でした。これは人間が理解しやすい一方、**語彙にない概念は中間表現として使えない**という制約がありました。

対して**ソフト思考**は、語彙全体の埋め込みベクトルを確率で重み付けして足し合わせる「連続的なベクトル」を生成します。これにより、離散トークンでは表現しにくい**抽象的な中間概念**も扱えるようになります。

### 解決した3つの課題

ソフト思考に強化学習（RLVR）を適用する際、以下の障壁がありました。

1. **ランダム性がない**: 決定論的に動くため、探索に必要な多様な推論パスが生成できない
2. **無効な表現が生まれる**: ノイズを加えると、事前学習済みのトークン空間から外れた意味不明なベクトルになる
3. **報酬の帰属が難しい**: どの出力確率の変更が報酬向上に寄与したかを計算できない

SofT-GRPO は **Gumbel ノイズ注入 + Gumbel-Softmax + Gumbel 再パラメータ化** の3技術でこれを解決しました。

### 実験が示した本質的な効果

| 指標 | 結果 | 意味 |
|------|------|------|
| **Pass@1** | 離散トークン GRPO をわずかに上回る | 1回生成でも既存手法と同等以上 |
| **Pass@32** | **平均 +2.19%** の大幅改善 | サンプリング数を増やすほど、ソフト思考の**探索空間の豊かさ**が活きる |
| **ドメイン外汎化** | 性能向上を確認 | 単なる過学習ではなく、推論能力そのものが強化されている |

Pass@32 で差が大きいのは、ソフト思考が「語彙に縛られない多様な中間表現」を作れるため、多数サンプリング時に**離散トークンでは到達できない推論パス**を発見できるからです。


### 一言でまとめると

SofT-GRPO は、**「LLM の推論を『単語の羅列』から『連続的な概念空間での思考』へ進化させ、その思考を報酬に基づいて最適化する基盤技術」** です。これにより、語彙の枠を超えたより柔軟で創造的な推論が可能になりました。
