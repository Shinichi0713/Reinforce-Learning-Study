


## グラフ理論とは

グラフ理論は「点（頂点）と線（辺）のつながり」を数学的に扱う分野です。現実世界の「ネットワーク」を抽象化するのに非常に便利で、SNSの友達関係、道路網、Webページのリンク構造など、さまざまなものがグラフとして表現できます。

### 1. グラフ理論の基本

__グラフとは__
- **頂点（ノード）**：もの（人・駅・Webページなど）
- **辺（エッジ）**：頂点同士の関係（友達関係・道路・リンクなど）

例：
- SNSの「友達」関係  
  → 頂点＝ユーザー、辺＝友達関係
- 路線図  
  → 頂点＝駅、辺＝路線
- Webページのリンク  
  → 頂点＝ページ、辺＝リンク

__グラフの種類__
- **無向グラフ**：辺に方向がない（例：友達関係）
- **有向グラフ**：辺に方向がある（例：Twitterのフォロー）
- **重み付きグラフ**：辺に重み（距離・コストなど）がある（例：道路の距離）

__よく使う概念__
- **次数**：ある頂点につながっている辺の数
- **経路**：ある頂点から別の頂点へたどる辺の列
- **連結**：どの頂点からどの頂点へも経路があるか
- **木**：閉路（ループ）のない連結グラフ（例：組織図）

### 2. ニューラルネットワークとの関連

ニューラルネットワークは、**「計算ユニット（ニューロン）がグラフ構造でつながったもの」**と見なせます。

__ニューラルネットワークをグラフとして見る__
- **頂点**：ニューロン（ノード）
- **辺**：ニューロン間の結合（重み付きの有向辺）

例：多層パーセプトロン（MLP）
- 入力層・隠れ層・出力層の各ニューロンが頂点
- 層間の結合が有向辺（入力 → 隠れ → 出力）
- 各辺には「重み」と「バイアス」が付いている

__グラフニューラルネットワーク（GNN）__
近年、**グラフそのものを入力として扱うニューラルネットワーク**（GNN）が注目されています。

- 入力：グラフ（頂点・辺・特徴ベクトル）
- 出力：  
  - グラフ全体のラベル（例：分子が毒性を持つか）  
  - 各頂点のラベル（例：SNSユーザーの興味カテゴリ）  
  - 辺の予測（例：今後友達になる確率）

GNNでは、各頂点が「近傍の情報」を集約しながら、繰り返し更新されていきます。  
→ グラフの「構造」と「特徴」の両方を学習できる

### 3. グラフ理論がニューラルネットワークに役立つ理由

1. **ネットワーク構造の理解**  
   層の数、結合の密度、情報の流れをグラフとして可視化・解析できる。

2. **表現力の理解**  
   どのようなグラフ構造を持つネットワークが、どのような関数を表現できるか（例：万能近似定理）を考える際に、グラフの視点が役立つ。

3. **GNNの設計**  
   グラフの性質（連結成分、中心性、コミュニティ構造など）を活かしたニューラルネットワーク設計が可能になる。
