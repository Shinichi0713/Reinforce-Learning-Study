## 強化学習で方策を用いるモチベーション

まずいきなりですが。
強化学習は 行動の価値を学習するパターンと、行動の選択ルールである方策を学習するパターンの2派にわかれます。
そして後者の強化学習が現在の主流です。

強化学習で方策を用いるモチベーションは、一言で言うと、

> **価値関数だけでは扱いにくい問題（連続行動空間、確率的方策、大規模・複雑な方策など）を、直接「行動ルール」を学習することで解決したいから**
> です。

### 1. 価値関数ベースの手法の限界

強化学習には、大きく分けて

- **価値関数ベース（value-based）**：Q学習など
- **方策ベース（policy-based）**：方策勾配法など

があります。

価値関数ベースの手法（例：Q学習）では、

- 各状態・行動の「価値」 
  $$
  { Q(s,a) }
  $$

   を学習し、
- その価値が最大になる行動を選ぶ

というアプローチを取ります。

この方法には、次のような限界があります。

__1.1 行動選択が「最大値」に固定されがち__

Q学習では、基本的に

$$
{ a^* = \arg\max_a Q(s,a) }
$$

という行動を選びます。

- これでは**探索が乏しくなりやすい**（常に「今一番良さそうな行動」を選ぶ）
- 確率的な行動選択をしたい場合（例：探索と活用のバランス）には、追加の工夫（
  $$
  { \epsilon }
  $$

  -greedy など）が必要

__1.2 連続行動空間では扱いにくい__

連続的な行動（例：ロボットの関節トルク、車のハンドル角度）では、

- 行動空間が無限（あるいは非常に高次元）
- $$
  { \arg\max_a Q(s,a) }$$ を求めるのが難しい（最適化問題になる）
  $$

という問題があります。

__1.3 複雑な方策を直接表現しにくい__

価値関数 

$$
{ Q(s,a) }
$$

 は「状態・行動のペア」に対するスカラー値です。![1779586742750](image/1_policy_grad_theorem_converted/1779586742750.png)

- 方策そのもの（「どの状態でどの行動をどの確率で選ぶか」）は、間接的にしか表現されない
- 複雑な行動ルール（例：階層的な方策、メモリを持つ方策）を
  直接学習しにくい

### 2. 方策ベースの手法の利点

一方、方策ベースの手法では、**方策そのもの**をパラメータ化して学習します。

- 例：
  $$
  { \pi_\theta(a|s) }
  $$

   をニューラルネットで表現

これには次のような利点があります。

__2.1 確率的な方策で自然に探索できる__

方策 

$$
{ \pi_\theta(a|s) }
$$

 は確率分布なので、

- 高い確率の行動を選びつつも、低い確率の行動もたまに選ぶ
- これが**自然な探索**になる

確率的方策を使うことで、

$$
{ \epsilon }
$$

-greedy のような追加の探索戦略が不要になる場合もあります。

__2.2 連続行動空間に直接適用できる__

方策を連続分布（例：ガウス分布）でパラメータ化すれば、

- 連続的な行動をそのまま出力できる
- 方策勾配法で、その分布のパラメータ（平均・分散など）を学習できる

これにより、連続行動空間の問題を**自然に扱える**ようになります。

__2.3 複雑な方策を直接学習できる__

方策をニューラルネットなどで表現すれば、

- 階層的な構造
- メモリ（RNN/LSTM）
- 注意力機構

など、**複雑な行動ルール**を直接学習できます。

価値関数ベースでは「価値」を学習し、そこから間接的に方策を決めますが、方策ベースでは「行動ルールそのもの」を学習するため、より柔軟で表現力の高い方策を設計しやすくなってくるわけです。

## 解決したい課題

ザックリいうと行動を決めるルールである方策を計算する上で、計算上困難な点があります。
そしてこれを解ける形に持っていきたいということが、今回紹介する定理が導入されることとなった理由です。

### 1. 方策パラメータとは何か

__1.1 方策（policy）とは__

強化学習では、エージェントが「どの状態でどの行動を取るか」を決めるルールを**方策（policy）** と呼びます。

- 例：
  - 「ロボットが前に進もうとしているときは、前進アクションを高確率で選ぶ」
  - 「ゲームで敵が近づいてきたら、攻撃行動を選ぶ」

この「ルール」を、数学的には確率分布 

$$
{ \pi(a|s) }
$$

 で表します。

- $$
  { s }$$：状態（state）
  $$
- $$
  { a }$$：行動（action）
  $$
- $$
  { \pi(a|s) }$$：状態 $${ s }$$ で行動 $${ a }$$ を選ぶ確率
  $$

__1.2 方策パラメータとは__

現実の問題では、状態の数が膨大（あるいは連続）なので、
「すべての状態ごとに確率表を用意する」ことはできません。

そこで、方策を**パラメータを持つ関数**で近似します。

- 例：ニューラルネットワーク
  - 入力：状態 
    $$
    { s }
    $$

    （画像やセンサー値など）
  - 出力：各行動を選ぶ確率 
    $$
    { \pi_\theta(a|s) }
    $$
  - $$
    { \theta }$$：ネットワークの重み（パラメータ）
    $$

この 

$$
{ \theta }
$$

 が**方策パラメータ**です。

- $$
  { \theta }$$ を少し変えると、すべての状態での行動選択の傾向が少し変わる
  $$
- 良い 
  $$
  { \theta }
  $$

   を見つければ、期待報酬が高くなる

というわけです。

### 2. なぜ状態分布の勾配が実用上計算困難か

__2.1 期待報酬は「状態分布」と「方策」の両方に依存する__

期待報酬 

$$
{ J(\theta) }
$$

 は、ざっくり言うと

$$
{ J(\theta) = \mathbb{E}_{s \sim d^\pi_\theta, a \sim \pi_\theta(\cdot|s)} [\text{報酬}] }
$$

という形で表せます。

ここで重要なのは、

- **状態分布 
  $$
  { d^\pi_\theta(s) }
  $$

  **：方策 
  $$
  { \pi_\theta }
  $$

   に従って行動していると、どの状態にどのくらいの頻度で訪れるか
- **方策 
  $$
  { \pi_\theta(a|s) }
  $$

  **：その状態でどの行動をどの確率で選ぶか

の**両方が** 

 **に依存している**ことです。

__2.2 勾配を取ると「状態分布の勾配」が出てくる__

$$
{ \theta }$$ を少し変えたときの $${ J(\theta) }$$ の変化（勾配）を考えると、  
積の微分・合成関数の微分のルールから、

$${ \nabla_\theta J(\theta) = (\text{状態分布の変化による寄与}) + (\text{方策の変化による寄与}) }
$$

のような形になります。

具体的には、

- 第1項：
  $$
  { \nabla_\theta d^\pi_\theta(s) }
  $$

   を含む項
  → 「パラメータを変えたとき、どの状態にどれだけ多く（少なく）行くようになるか」の効果
- 第2項：
  $$
  { \nabla_\theta \pi_\theta(a|s) }
  $$

   を含む項
  → 「同じ状態にいるときに、行動選択の確率がどう変わるか」の効果

となります。

__2.3 状態分布の勾配がなぜ難しいか__

問題は、**第1項の** 

 です。

- $$
  { d^\pi_\theta(s) }$$ 自体が、  
  「方策 $${ \pi_\theta }$$ で長期的に行動したときの、状態の出現頻度」を表す
  $$
- これは**定常分布**や**訪問頻度**のような概念で、
  環境のダイナミクス（状態遷移確率）と方策の相互作用で決まる

実用的には、

- 環境の遷移確率 

  $$
  { P(s'|s,a) }
  $$

   が明示的に分からないことが多い
- 分かっていたとしても、状態空間が巨大（あるいは連続）で、

  $$
  { d^\pi_\theta(s) }$$ を解析的に求めるのはほぼ不可能
  $$
- ましてや、その 

  $$
  { \theta }
  $$

   による微分 
  $$
  { \nabla_\theta d^\pi_\theta(s) }
  $$

   を
  閉じた形で書くのはさらに困難

という状況です。

__2.4 サンプルで近似するのも難しい__

「解析的に無理なら、サンプルで近似すればいいのでは？」と思うかもしれませんが、

- サンプルで 

  $$
  { d^\pi_\theta(s) }
  $$

   を近似的に得ることは可能（たくさんエピソードを回す）
- しかし、

  $$
  { \nabla_\theta d^\pi_\theta(s) }
  $$

   は
  「
  $$
  { \theta }
  $$

   を少し変えたときの 
  $$
  { d^\pi_\theta(s) }
  $$

   の変化」なので、- 異なる 
    $$
    { \theta }
    $$

     で十分なサンプルを取る必要がある
  - しかもその差分を取ることで勾配を近似する必要がある

これは計算コストが非常に高く、実用的ではありません。

### 3. 方策勾配定理が解決すること

方策勾配定理は、この厄介な「状態分布の勾配」を**うまく消してくれる**魔法のような定理です。

結果として、

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{s \sim d^\pi_\theta, a \sim \pi_\theta(\cdot|s)} \left[ \nabla_\theta \log \pi_\theta(a|s) \; Q^\pi(s,a) \right] }
$$

のように、

- **状態分布 
  $$
  { d^\pi_\theta(s) }
  $$

   の勾配が現れない**
- 代わりに、
  - $$
    { \nabla_\theta \log \pi_\theta(a|s) }$$：方策のスコア関数（計算しやすい）
    $$
  - $$
    { Q^\pi(s,a) }$$：価値関数（サンプルや関数近似で推定できる）
    $$

の積の期待値になる

という形に変えてくれます。

これにより、

- 実際に方策で行動してサンプルを取り、
- 各ステップで 
  $$
  { \nabla_\theta \log \pi_\theta(a|s) }
  $$

   と
  価値（あるいは収益）を掛けて平均する

という**実用的なアルゴリズム（REINFORCE, actor-critic など）** が可能になります。

## 方策勾配定理の導出

方策勾配定理の導出を、できるだけ分かりやすく説明します。
ここでは、**有限ホライゾン・割引報酬**の設定で、エピソード型の強化学習を想定します。

### 1. 設定と記号

- 方策：

  $$
  { \pi_\theta(a|s) }
  $$

  （パラメータ 
  $$
  { \theta }
  $$

  ）
- 状態遷移確率：

  $$
  { P(s'|s,a) }
  $$
- 報酬：

  $$
  { r(s,a,s') }
  $$
- 割引率：

  $$
  { \gamma \in [0,1] }
  $$
- エピソード長：

  $$
  { T }
  $$

  （有限）

目的関数（期待収益）は

$$
{ J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^{T-1} \gamma^t r_{t+1} \right] }
$$

とします（ここで 

$$
{ r_{t+1} = r(s_t, a_t, s_{t+1}) }
$$

）。

### 2. 素朴な勾配計算と問題点

素直に勾配を取ると、

$$
{ \nabla_\theta J(\theta) = \nabla_\theta \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^{T-1} \gamma^t r_{t+1} \right] }
$$

ここで、軌跡 

$$
{ \tau }
$$

 の確率は

$$
{ p_\theta(\tau) = p(s_0) \prod_{t=0}^{T-1} \pi_\theta(a_t|s_t) P(s_{t+1}|s_t,a_t) }
$$

です。

期待値は

$$
{ \mathbb{E}_{\tau \sim \pi_\theta}[f(\tau)] = \int p_\theta(\tau) f(\tau) \, d\tau }
$$

なので、

$$
{ \nabla_\theta J(\theta) = \int \nabla_\theta p_\theta(\tau) \left( \sum_{t=0}^{T-1} \gamma^t r_{t+1} \right) d\tau + \int p_\theta(\tau) \nabla_\theta \left( \sum_{t=0}^{T-1} \gamma^t r_{t+1} \right) d\tau }
$$

となります。

- 第2項：報酬は環境の関数であり、
  $$
  { \theta }
  $$

   に依存しないと仮定するのが普通なので、0 になります。
- 第1項：
  $$
  { \nabla_\theta p_\theta(\tau) }
  $$

   が問題です。

ここで、

$$
{ \nabla_\theta p_\theta(\tau) = p_\theta(\tau) \nabla_\theta \log p_\theta(\tau) }
$$

という恒等式（**ログ微分トリック**）を使うと、

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \nabla_\theta \log p_\theta(\tau) \cdot \sum_{t=0}^{T-1} \gamma^t r_{t+1} \right] }
$$

となります。

### 3. 
$$
{ \nabla_\theta \log p_\theta(\tau) }
$$

 の計算

$$
{ p_\theta(\tau) = p(s_0) \prod_{t=0}^{T-1} \pi_\theta(a_t|s_t) P(s_{t+1}|s_t,a_t) }
$$

なので、対数を取ると

$$
{ \log p_\theta(\tau) = \log p(s_0) + \sum_{t=0}^{T-1} \left[ \log \pi_\theta(a_t|s_t) + \log P(s_{t+1}|s_t,a_t) \right] }
$$

よって、

$$
{ \nabla_\theta \log p_\theta(\tau) = \sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t|s_t) }
$$

- 初期状態分布 

  $$
  { p(s_0) }
  $$

   と遷移確率 
  $$
  { P(s_{t+1}|s_t,a_t) }
  $$

   は 
  $$
  { \theta }
  $$

   に依存しないと仮定
- したがって、

  $$
  { \nabla_\theta }
  $$

   を取ると消える

これが重要なポイントで、**状態分布の勾配が直接現れない**理由です。

### 4. 勾配の式への代入

先ほどの式に代入すると、

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \left( \sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t|s_t) \right) \cdot \left( \sum_{k=0}^{T-1} \gamma^k r_{k+1} \right) \right] }
$$

ここで、**時刻** 

 **より前の報酬は、時刻 
$$
{ t }
$$

 の行動には影響しない**という性質（因果性）を使うと、
この二重和を整理できます。

より明確に書くと、

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot \left( \sum_{k=t}^{T-1} \gamma^k r_{k+1} \right) \right] }
$$

となります（

$$
{ k < t }
$$

 の項は期待値で打ち消される）。

ここで、時刻 

$$
{ t }
$$

 からの収益を

$$
{ G_t = \sum_{k=t}^{T-1} \gamma^{k-t} r_{k+1} }
$$

と定義すると（割引を調整）、

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t|s_t) \; \gamma^t G_t \right] }
$$

となります（

$$
{ \gamma^t }
$$

 は適宜吸収させてもよい）。

### 5. より一般的な形（状態価値関数を使った形）

上の式は、収益 

$$
{ G_t }
$$

 をそのまま使う形（REINFORCE 型）ですが、
より一般的には、**状態価値関数 
$$
{ V^\pi(s) }
$$

** や **行動価値関数 
$$
{ Q^\pi(s,a) }
$$

** を使った形に書き換えられます。

__5.1 行動価値関数を使った形__

定義より、

$$
{ Q^\pi(s_t,a_t) = \mathbb{E}_{\pi_\theta} \left[ \sum_{k=t}^{T-1} \gamma^{k-t} r_{k+1} \;\big|\; s_t, a_t \right] }
$$

なので、条件付き期待値を取ると、

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t|s_t) \; Q^\pi(s_t,a_t) \right] }
$$

と書けます。

__5.2 状態分布で書き直す__

さらに、状態分布 

$$
{ d^\pi_\theta(s) }
$$

（方策 
$$
{ \pi_\theta }
$$

 のもとでの状態の訪問頻度）を使うと、

$$
{ \nabla_\theta J(\theta) = \int_S d^\pi_\theta(s) \int_A \pi_\theta(a|s) \nabla_\theta \log \pi_\theta(a|s) \; Q^\pi(s,a) \, da \, ds }
$$

となります。

ここで、

$$
{ \nabla_\theta \pi_\theta(a|s) = \pi_\theta(a|s) \nabla_\theta \log \pi_\theta(a|s) }
$$

なので、

$$
{ \nabla_\theta J(\theta) = \int_S d^\pi_\theta(s) \int_A \nabla_\theta \pi_\theta(a|s) \; Q^\pi(s,a) \, da \, ds }
$$

とも書けます。

これが、**方策勾配定理**の一般的な形です。

## 方策勾配定理のご利益

前節で導出した方策勾配定理ですが、ご利益はなんでしょう。
方策勾配定理を導入することのご利益は、主に次の3点に集約できます。

1. **状態分布の勾配を直接扱わずに済む**
2. **サンプルで勾配を近似できる（モンテカルロ近似が可能）**
3. **価値関数と組み合わせて、分散を抑えた安定した学習ができる**

以下、それぞれ詳しく説明します。

### 1. 状態分布の勾配を直接扱わずに済む

__1.1 本来の難しさ__

期待報酬 

$$
{ J(\theta) }
$$

 は、一般に

$$
{ J(\theta) = \mathbb{E}_{s \sim d^\pi_\theta, a \sim \pi_\theta(\cdot|s)} [\text{報酬}] }
$$

のように、**状態分布** 

 が 
$$
{ \theta }
$$

 に依存します。

もしこれを素直に 

$$
{ \theta }
$$

 で微分しようとすると、

$$
{ \nabla_\theta J(\theta) = (\text{状態分布の変化による寄与}) + (\text{方策の変化による寄与}) }
$$

となり、

 という項が出てきます。

- これは「パラメータを少し変えたとき、どの状態にどれだけ多く（少なく）行くようになるか」を表す
- しかし、実際の環境では 
  $$
  { d^\pi_\theta(s) }
  $$

   すら明示的に分からないことが多く、
  ましてやその勾配を計算するのは極めて困難

__1.2 方策勾配定理が解決すること__

方策勾配定理は、この厄介な項を**うまく消してくれる**定理です。

典型的な形は：

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{s \sim d^\pi_\theta, a \sim \pi_\theta(\cdot|s)} \left[ \nabla_\theta \log \pi_\theta(a|s) \; Q^\pi(s,a) \right] }
$$

あるいはエピソード型では：

$$
{ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \; G_t \right] }
$$

この形では、

- **状態分布 
  $$
  { d^\pi_\theta(s) }
  $$

   の勾配が現れない**
- 代わりに、**スコア関数 
  $$
  { \nabla_\theta \log \pi_\theta(a|s) }
  $$

  ** と
  **価値関数 
  $$
  { Q^\pi(s,a) }
  $$

   または収益 
  $$
  { G_t }
  $$

  ** の積の期待値になっている

という特徴があります。

**メリット**：
状態分布の勾配を直接計算する必要がなくなり、
実用的なアルゴリズムを構築できるようになります。

### 2. サンプルで勾配を近似できる（モンテカルロ近似）

方策勾配定理によって得られた形

$$
{ \nabla_\theta J(\theta) \approx \sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \; G_t }
$$

は、**モンテカルロ近似**が可能です。

具体的には、

1. 方策 

   $$
   { \pi_\theta }
   $$

    で実際に行動して、軌跡 
   $$
   { \tau }
   $$

    をサンプルする
2. 各時刻 

   $$
   { t }
   $$

    で 
   $$
   { \nabla_\theta \log \pi_\theta(a_t|s_t) }
   $$

    と 
   $$
   { G_t }
   $$

    を計算する
3. それらを足し合わせて、勾配の近似とする

という操作で、**サンプルベースの学習**ができます。

**メリット**：

- 環境の遷移確率 
  $$
  { P(s'|s,a) }
  $$

   が分からなくても学習できる（モデルフリー）
- 実装が比較的シンプル（REINFORCE など）

### 3. 価値関数と組み合わせて、分散を抑えた安定した学習ができる

__3.1 純粋なモンテカルロの問題点__

REINFORCE のように、収益 

$$
{ G_t }
$$

 をそのまま使うと、

- $$
  { G_t }$$ のばらつき（分散）が大きい
  $$
- その結果、勾配更新の分散も大きくなり、学習が不安定

という問題があります。

__3.2 actor-critic による解決__

方策勾配定理の形

$$
{ \nabla_\theta J(\theta) = \mathbb{E} \left[ \nabla_\theta \log \pi_\theta(a|s) \; Q^\pi(s,a) \right] }
$$

から出発し、

$$
{ Q^\pi(s,a) }
$$

 を**価値関数で近似**することで、
**actor-critic** 型のアルゴリズムが導かれます。

よく使われるのは、**アドバンテージ関数** 

$$
{ A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s) }
$$

 を使う形：

$$
{ \nabla_\theta J(\theta) \approx \sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \; A(s_t,a_t) }
$$

ここで 

$$
{ A(s_t,a_t) }
$$

 は、critic が学習した価値関数を使って推定されます（例：TD誤差 
$$
{ \delta_t }
$$

）。

**メリット**：

- 基準（baseline）
  $$
  { V(s_t) }
  $$

   を引くことで、更新信号の分散を抑えられる
- 学習がより安定し、収束が早くなる
- オンライン（エピソード終了を待たず）に更新できる
