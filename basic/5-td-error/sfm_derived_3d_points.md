3D点群データを精度よく得たいという要望があります。
3D点群には精度を影響するパラメータとしてカメラの内部パラメータやマップのオーバーラップがよく知られます。
ですが、この情報以外にも精度を左右するパラメータが存在します。

本日はそんなパラメータについて調査・研究した論文について読んでいきます。

本日テーマ：

> UAV-Based LiDAR and SfM-derived 3D Point Clouds of Forest Canopiesについて読んでいく

## 論文概要

論文「UAV-Based LiDAR and SfM-derived 3D Point Clouds of Forest Canopies – Observation Angles Matter」の概要を以下にまとめます。

### 研究の背景と目的

森林構造の正確な3Dマッピングは、生態系モニタリング、生物量推定、生息地解析などにおいて極めて重要です。近年、UAV（無人航空機）を搭載プラットフォームとしたLiDARとSfM（Structure-from-Motion）の両方が、森林キャノピーの詳細な3D点群を生成する手段として広く利用されています。

LiDARは高精度で、ある程度キャノピーを貫通して林下や地形を捉えられる強みがありますが、高価で大型のプラットフォームが必要です。一方、SfMは重複画像から3D表面を再構成する手法で、低コストかつ運用が柔軟ですが、特に密なキャノピーでは遮蔽（オクルージョン）の問題があり、林下や地形の精度が低下しやすいという課題があります。

本研究の目的は、**最適化された3D取得パラメータ（多数の画像と多様な観測角度）を用いたSfMが、最先端のUAV搭載LiDARと比較してどの程度の性能を示すかを評価すること**です。

### 研究地とデータ取得

- **研究地**: スイス・ビルメンスドルフ近郊の「Ramerenwald」（温帯混交林）
- **調査プロット**: 50m×50mの4つのプロット（うち本研究では広葉樹優占のFP05と針葉樹優占のFP08を使用）
- **調査時期**: 2024年3月26日（落葉期・leaf-off）と2024年5月29日（展葉期・leaf-on）の2回
- **使用機器**:
  - LiDAR: Riegl miniVUX（DJI M600搭載）
  - SfM: DJI Mavic 3 Multispectral（20MP RGBカメラ）
- **取得高度**: 両システムとも地上約60–80m
- **SfMの取得戦略**:
  - **高品質SfM**: 2つのダブルグリッド飛行パターンを45度ずつ回転させ、カメラをオフナディア（70度傾斜）に設定。多様な観測角度からの多数の画像を取得。
  - **標準SfM**: 従来型のナディア（真下向き）カメラによる単一ダブルグリッド飛行（比較用ベースライン）

両システムのデータは同日に連続して取得され、時間差による環境条件の変化を排除しています。

### 比較・評価方法

取得した全データセットから3D点群を生成し、以下の方法で比較しました。

1. **視覚的比較**
2. **垂直プロファイル（高さ方向の点分布）の比較**
3. **3つのキャノピー指標**:
   - **CH（Canopy Height / キャノピー高さ）**
   - **FCO（Fractional Cover / 被覆率）**
   - **FHD（Foliage Height Diversity / 葉群高さ多様性）**

### 主な結果と結論

__SfMの性能__

- 最適化された飛行計画（多様な観測角度）を用いたSfMは、**専用LiDARシステムと同等品質の点群を生成できる**ことが示されました。
- キャノピー高さや垂直プロファイルについて、高品質SfMデータセットはLiDARとほぼ一致しました。
- 森林の全体的な構造は、両手法とも良好に捉えられました。

__LiDARの優位性__

- LiDARは**キャノピー貫通能力に優れ**、林下植生や地形の検出において明らかに優位でした。
- 密なキャノピーにおける複雑な指標（FCOやFHD）の導出では、SfMは課題を残しました。

__総合的な評価__

- **SfM（3D最適化飛行計画あり）は、コスト効率の高い代替手段**となり得ます。特に、詳細な林下情報がそれほど重要でない場合や、LiDARベースのDTM（数値地形モデル）が既に利用可能な場合に有効です。
- しかし、**微細な垂直構造の捉え方においては、LiDARが依然としてより堅牢なツール**であることも確認されました。

### 研究の意義

従来のLiDARとSfMの比較研究では、主に固定翼機やナディア指向の撮影構成が用いられ、2Dオルソモザイク生成に最適化された設定が多かったため、SfMの真のポテンシャルが十分に評価されていませんでした。本研究は、**多様な観測角度を活用したSfMの3D取得戦略が、森林構造マッピングにおいてLiDARに近い性能を発揮しうる**ことを実証した点に大きな意義があります。`<source-chip title="DGPF" url="https://www.dgpf.de/src/tagung/jt2025/proceedings/paper/22_3LT2025_Morsdorf_et_al.pdf" />`

## 評価指標

本研究で用いられた性能指標は、森林構造を定量的に評価するための3つの指標です。以下にそれぞれの定義と本研究での役割を説明します。

### 1. CH（Canopy Height / キャノピー高さ）

**定義**:
キャノピー高さは、各位置における樹冠表面の高さを示す指標です。一般的に、点群データから得られた植被の高さ（DSM: 地表モデル）から地形高さ（DTM: 数値地形モデル）を差し引くことで算出されます。

**本研究での評価内容**:

- LiDARはキャノピー貫通能力により高精度なDTMを生成できるため、直接的な高さ測定が可能です。
- SfMは密なキャノピー下の地形検出が困難なため、DTMの精度が低下しやすく、結果としてCHの精度にも影響が出る可能性があります。
- 結果として、**高品質SfM（多様な観測角度）はLiDARとほぼ同等のCHを再現**できました。

### 2. FCO（Fractional Cover /  fractional canopy cover / 被覆率）

**定義**:
キャノピー被覆率は、水平面上で樹冠が占める割合を示す指標です。点群データを水平方向に積分・投影し、植被が存在するピクセルやグリッドセルの割合を算出することで求められます。0（植被なし）から1（完全に植被で覆われている）の範囲で表されます。

**本研究での評価内容**:

- 森林の水平方向の密さや隙間の分布を評価する指標です。
- 結果として、**SfMは密なキャノピーにおけるFCOの導出に苦労**しました。これは、SfMが画像ベースであるため、密な樹冠の隙間を通じた下層の視認性がLiDARに比べて低いことに起因します。
- 特に複雑な構造を持つ林分では、LiDARの優位性が顕著になりました。

### 3. FHD（Foliage Height Diversity / 葉群高さ多様性）

**定義**:
葉群高さ多様性は、垂直方向の植被構造の複雑さや多様性を定量化する指標です。一般的に、植被の高さをいくつかの階層（ビン）に分け、各階層に含まれる点の割合（または葉面積の割合）に基づいて**シャノン多様性指数（Shannon diversity index）** などを適用して算出されます。値が高いほど、垂直方向に多様な植被構造（上層、中層、下層などに葉が分布している）を持つことを示します。

**本研究での評価内容**:

- 森林の垂直構造の複雑さを捉える重要な生態指標です。
- 結果として、**SfMはFHDのような複雑な指標の導出において、特に密なキャノピーで課題**を示しました。
- LiDARは多重回波により垂直方向の葉群分布を詳細に捉えられるため、FHDの推定においてより堅牢な結果を示しました。

### 指標の比較まとめ

| 指標          | 評価対象             | LiDARの優位性              | SfMの性能                   |
| ------------- | -------------------- | -------------------------- | --------------------------- |
| **CH**  | 樹冠の高さ           | 地形からの直接測定が高精度 | 最適化取得でLiDARとほぼ同等 |
| **FCO** | 水平方向の被覆率     | 密なキャノピーでも高精度   | 密な林分で課題あり          |
| **FHD** | 垂直方向の構造多様性 | 多重回波により最も優位     | 複雑な構造で苦労            |

### 補足：比較方法

これらの指標は、以下の3段階で比較されました。

1. **視覚的比較**: 点群の外観的な違いを確認
2. **垂直プロファイルの比較**: 高さ方向の点分布を比較
3. **3指標の数値的比較**: CH、FCO、FHDを定量的に算出し、LiDARと2種類のSfM（高品質・標準）の間で比較

これらの指標を組み合わせることで、本研究はLiDARとSfMが森林構造のどの側面を捉えるのに優れているか、またSfMの取得戦略の最適化がどの程度の改善効果をもたらすかを包括的に評価しています。`<source-chip title="DGPF" url="https://www.dgpf.de/src/tagung/jt2025/proceedings/paper/22_3LT2025_Morsdorf_et_al.pdf" />`

## 結果

本研究の主な結果を、3つの評価観点ごとにまとめます。

### 1. 点群品質と森林構造の再現性

- **高品質SfM（多様な観測角度）** は、**専用LiDARシステムと同等品質の3D点群を生成できる**ことが示されました。
- 両手法とも、森林構造の全体像を良好に捉えることができました。
- **キャノピー高さ（CH）と垂直プロファイル**については、高品質SfMデータセットがLiDARとほぼ一致する結果となりました。

![1787444869699](image/sfm_derived_3d_points/1787444869699.png)

### 2. 各性能指標での比較結果

| 指標                            | 結果                                           |
| ------------------------------- | ---------------------------------------------- |
| **CH（キャノピー高さ）**  | 高品質SfMはLiDARとほぼ同等の精度で再現可能     |
| **FCO（被覆率）**         | SfMは密なキャノピーで課題あり。LiDARが優位     |
| **FHD（葉群高さ多様性）** | SfMは複雑な垂直構造の定量化で苦労。LiDARが堅牢 |

### 3. LiDARの優位性

- **キャノピー貫通能力**においてLiDARが明らかに優位でした。
- これにより、**林下植生（understory）と地形の検出**がより正確に行えました。
- 特に**密なキャノピー環境**では、LiDARの多重回波による微細な垂直構造の捉え方がSfMを上回りました。

### 4. SfMの有効性と限界

- **有効性**: 最適化された取得戦略（多様な観測角度・オフナディア撮影）を用いたSfMは、コスト効率の高い代替手段となり得ます。
- **限界**: 一般的な植被プロファイルは再現できましたが、**複雑な指標（FCOやFHD）や密なキャノピー下の構造**では、LiDARに比べて精度が低下しました。

### 5. 総合的な結論

- **SfM（3D最適化飛行計画あり）** は、以下の条件で実用的な選択肢となります：
  - 詳細な林下情報がそれほど重要でない場合
  - LiDARベースのDTM（数値地形モデル）が既に利用可能な場合
- しかし、**微細な垂直複雑性を捉える必要がある場合は、LiDARが依然としてより堅牢なツール**であることが確認されました。
- 従来型のナディア撮影SfMと比較して、**多様な観測角度を活用したSfMは森林構造マッピングの性能を大幅に向上させる**ことが実証されました。`<source-chip title="DGPF" url="https://www.dgpf.de/src/tagung/jt2025/proceedings/paper/22_3LT2025_Morsdorf_et_al.pdf" />`

## 総括

本論文の本質的な結論は、**SfMによる3D点群の精度は、カメラの内部パラメータや画像のオーバーラップだけでなく、「観測角度の多様性」という取得戦略が決定的に左右する**という点に集約されます。

### 本質的な結論

**1. 観測角度の多様性が3D点群精度の鍵である**

カメラのキャリブレーションや画像の重複率（オーバーラップ）はSfMの精度にとって重要なパラメータとして知られていますが、本研究はそれに加えて、**撮影方向の多様性（ナディアだけでなくオフナディア方向からの撮影、複数方向からのアプローチ）が3D再構成の精度を飛躍的に向上させる**ことを実証しました。2つの飛行グリッドを45度回転させ、カメラを70度傾斜させることで、キャノピー隙間からの下層視認性が向上し、遮蔽（オクルージョン）の影響を大幅に低減できました。

**2. 最適化されたSfMはLiDARに匹敵するが、根本的な限界も存在する**

取得戦略を最適化したSfMは、キャノピー高さ（CH）や全体的な垂直プロファイルにおいて最先端のUAV-LiDARとほぼ同等の品質を実現しました。しかし、SfMは画像ベースの受動的センシングであるため、**キャノピー貫通能力に根本的な限界**があります。結果として、林下植生の検出や、被覆率（FCO）・葉群高さ多様性（FHD）といった微細な垂直構造の定量化では、LiDARが依然として優位なツールであり続けます。

**3. 応用上の示唆：コストと精度のトレードオフを観測角度で最適化できる**

LiDARは高精度だが高価格・大型プラットフォームが必要である一方、SfMは低コストで柔軟です。本研究は、**SfMの取得戦略を「3D最適化」（多様な観測角度）に設計し直すことで、従来の2Dオルソモザイク重視のナディア撮影を大きく上回る精度が得られ、LiDARに代替しうるレベルまで性能を引き上げられる**ことを示しました。これは、詳細な林下情報が必須でない場面や、LiDARによる地形データ（DTM）が既存である場合に、SfMが極めてコスト効率の高い選択肢となりうることを意味します。

### 一言でまとめると

**「3D点群の精度を追求する際、カメラ内部パラメータやオーバーラップだけでなく、撮影角度の多様性（観測角度）こそがSfMの性能を最大限に引き出す決定的なパラメータである。しかし、キャノピー貫通や微細な垂直構造の捉え方ではLiDARの優位性は揺るがない。」**

このことが、論文タイトル「Observation Angles Matter（観測角度が重要である）」の核心です。`<source-chip title="DGPF" url="https://www.dgpf.de/src/tagung/jt2025/proceedings/paper/22_3LT2025_Morsdorf_et_al.pdf" />`
